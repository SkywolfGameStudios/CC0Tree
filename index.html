Want the original Blender source (.blend) files, or a pre-packaged zip of every FBX so you don't have to grab them one by one? Both are Patreon supporter perks. Everything here stays free either way — download assets individually above, or grab the full repo as-is.

🙋
CC0Tree is made by one person, in the hours between other projects. Every model shares the same hand-tuned gradient-shaded low-poly style — modeled, UV'd, and exported one at a time, not mass-produced. That consistency is what makes it a library instead of a pile of random files, and free is a choice, not a given. If an asset saved you time, a few dollars on Patreon or a GitHub sponsorship is what keeps new ones coming every week.

🎁 Supporters can request a model

Every asset stays free for everyone. But if you've supported CC0Tree, you can also ask for a specific model and I'll make it and add it to the library.

  1. Support CC0Tree on any platform above (one-time or monthly).
  2. Contact me by email or Discord so I can verify you.
  3. Request any model you'd like to see.
  4. I'll make and upload it to the library.
  5. I'll notify you as soon as it's live.
✉️ Request by Email 💬 Request on Discord

Requests are for supporters only. If you've only downloaded the free models, everything is still yours to use, and you're welcome to suggest an idea on GitHub. Suggestions are read, but not guaranteed. To make sure a request reaches me, please use email or Discord, since comments and messages elsewhere might get missed.
